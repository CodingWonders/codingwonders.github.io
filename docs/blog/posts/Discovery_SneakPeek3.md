# What's Next for "Discovery": Comparing images 
 
Answering what the difference between 2 image files is has become easier. 
 
<!-- more --> 
 
Picture this: you may have a set of image files and may need to know what differs between both of them. While you can leverage image information reports to view a basic set of differences, why not go a step further?

As such, *Discovery* will bring comprehensive image comparison features that will cover the following items:

- Image file information
- Packages
- Features
- AppX packages
- Capabilities
- Drivers
- Services
- File System entries
- Registry items

For plain text items, a diff-styled view will also be recorded, for independent file changes.

## Discovery is closer

The stable version of DISMTools 0.8.2 will come out really soon. After that comes the time to **discover what's next**. No more Sneak Peeks will be published because I want you to experience these features by yourself.

Stay tuned!
