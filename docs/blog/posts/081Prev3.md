# DISMTools 0.8.1 Preview 3 - Now available

The third preview of DISMTools 0.8.1 is now available, with new features and enhancements.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.1_pre_2681)

This version was released earlier than anticipated, for obvious reasons. Today is July 30, and DISMTools celebrates its anniversary one more time. <!-- Celebration tonight. Celebrate. Don't wait too late. -->

## What's new?

- The maximum amount of concurrent ISO creation tasks can now be configured up to a value of 10
- The Preinstallation Environment has received support for encrypting and decrypting, as well as getting information about, encryptable volumes
- The Sysprep Preparation Tool has been updated with BitLocker volume detection
- The following starter scripts are affected by this version:

| Starter Script                                     | Stage                       |  State  |
| :------------------------------------------------- | :-------------------------- | :-----: |
| **Prevent companion device software installation** | During System Configuration | **New** |

- When performing driver exports, multiple class names can now be selected
- Target exported drivers can now be organized in folders named after their class names

## What's fixed?

- Fixed some HiDPI issues
