# DISMTools 0.8 Preview 7 - Now available

The seventh preview of DISMTools 0.8 is now available, with new features and enhancements.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8_pre_2661)

## What's new?

- In portable installations, file associations can now be toggled for the Starter Script Editor
- The DynaLog log viewer has received support for event log filters
- Date properties can now be displayed in a Windows-native format

## How do I begin?

As always, you can begin contributing to the project by [**downloading this version today**](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8_pre_2661) and **reporting feedback to us**.
