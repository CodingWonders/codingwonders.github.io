# DISMTools 0.8.2 - The last of a series

<p align="center">
  <img src="https://github.com/user-attachments/assets/272e67f5-9072-441d-b21b-8c4f7801161e" />
</p>

DISMTools 0.8.2 is now available as a stable release, and comes with new features and enhancements.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.2_stable)

This version is also the last version in the 0.8 series. Infinity *might* be finite.

## What's new?

### Preinstallation Environment Helper

- HotInstall and the Sysprep Preparation Tool now create rollback environments to undo boot configuration changes and environment deployments:

<p align="center">
  <img src="https://github.com/user-attachments/assets/0c856fbc-254c-4446-be92-8af7080d0ab3" />
</p>

- The Sysprep Preparation Tool now disables sleep mode when running preparation tasks, and clears BITS transfer queues during Windows Update cache cleanup
- ISO file creation tasks in the ISO creator can now be double-clicked to load their settings
- Multiple image files can now be added to ISO files:

<p align="center">
    <img src="https://github.com/user-attachments/assets/c3a11b7e-0263-4c39-9f7c-24b098be9727" />
</p>

Leverage the image map to see what images in your machine correspond to which images in the installation medium:

<p align="center">
    <img src="https://github.com/user-attachments/assets/3a22ae6c-6789-45b7-80f9-8d541faf1269" />
</p>

If you picked the wrong image, you can now press B to go back:

<p align="center">
    <img src="https://github.com/user-attachments/assets/3f7f296c-3534-40fa-9d6b-f8abccdafee0" />
</p>

- The ISO creation features now support ESD files:

<p align="center">
  <img src="https://github.com/user-attachments/assets/7f8ae02d-9512-4579-acc0-56a41cbd7268" />

- BCD entries created by HotInstall and the Sysprep Preparation Tool are now localized

### System Service Manager

- You can now query and set Safe Mode preferences for services:

<p align="center">
  <img src="https://github.com/user-attachments/assets/d91897ce-e768-43a4-bbaa-a08e3d187e13" />

- The Service Manager allows you to visualize dependencies in diagrams you can export to pictures or Mermaid diagrams:

### Image Tasks

- Getting information about items is now done asynchronously, making the UI responsive
- When dropping AppX packages to the addition queue, you will now see a progress indicator:

<p align="center">
  <img src="https://github.com/user-attachments/assets/6c24b494-ada4-49bc-8a30-fdbac383b8c8" />
</p>

- When scanning AppX packages, 7-Zip is now forced to use all your processors
- When enabling features, sources can now be configured to be used only on features that require them

### Miscellaneous

- The window layout has been improved on 1024x768 screens
- 7-Zip has been updated to version 26.05
- Keyboard shortcuts have been added to create, open, and save projects
- DISMTools can now detect if the current network connection is metered and will warn you when attempting a download operation:

<p align="center">
  <img src="https://github.com/user-attachments/assets/ff02387f-19bb-48ce-be72-cd007038eb91" />
</p>

!!! note
	Detection capabilities are only supported on Windows 10 and later

- The following libraries and components have been updated:

| Component | Version in 0.8.1 | New version |
|:--:|:--:|:--:|
| [Markdig](https://github.com/xoofx/Markdig) | `1.3.2` | `1.5.1` |

- The language system has seen a major overhaul that makes it easier to translate the program to other languages. As a result of this change, German translations have been introduced ([#377](https://github.com/CodingWonders/DISMTools/pull/377), thanks @MinDeaDBlood)
- [News feed sources have been updated to point to the new CodingWonders Software website](https://codingwonders.github.io/blog/2026/10/10/revamping-the-news-source/)

## What's fixed?

*This will show the bugfixes in all the preview releases.*

- Fixed an exception when launching the AppX package information dialog on Windows 8 systems
- Fixed an issue where component store repair tasks would fail if no sources were specified
- Fixed an issue where some service dependencies and dependents would not be displayed in the Service Manager

## What's removed?

- [JScript support has been removed from unattended answer file features](https://codingwonders.github.io/blog/2026/10/11/removing-jscript-support-for-answer-files/)

## What changed since last preview release?

- DISMTools now uses WIMGAPI to query information about images to upload to a WDS server, greatly improving the reliability of the entire process
- Conflict resolution screens no longer appear in the PE Helper and the WDS Helper Client if the answer files in the disc/network and the image are the same
- The documentation has been updated

## How do I get started?

As always, you can begin contributing to the project by [**downloading this version today**](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.2_stable) and **reporting feedback to us**.

<p align="center">
  <img src="https://codingwonders.github.io/pictures/dt_relnotes/report_feedback.png">

Feedback is very crucial for the success of this project.

If you want to help us with something else (like documentation or artwork), we also welcome your suggestions. The help documentation content pages are available on [GitHub](https://github.com/CodingWonders/dt_help) and we encourage you to **contribute to them** so that we can make DISMTools easier to use.
