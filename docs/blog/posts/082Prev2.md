# DISMTools 0.8.2 Preview 2 - Now available

The second preview of DISMTools 0.8.2 is now available, with new features and enhancements.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.2_pre_2692)

## What's new?

- The Sysprep Preparation Tool now clears BITS transfer queues during Windows Update cache cleanup
- ISO file creation tasks in the ISO creator can now be double-clicked to load their settings
- The following starter scripts are affected by this version:

| Starter Script | Stage | State |
|:--|:--|:--|
| **Configure System Recovery Settings** | During System Configuration | **New** |

- The Service Manager allows you to visualize dependencies in diagrams you can export to pictures or Mermaid diagrams
- Configuring Safe Mode options for services can now carry changes over to dependencies and dependents
- Services critical for core Windows components can no longer be configured
- The following libraries and components have been updated:

|                  Component                  | Previous version | New version |
| :-----------------------------------------: | :--------------: | :---------: |
| [Markdig](https://github.com/xoofx/Markdig) |     `1.3.2`      |   `1.4.0`   |

- The language system has seen a major overhaul that makes it easier to translate the program to other languages. As a result of this change, German translations have been introduced

## What's fixed?

- Fixed an issue where component store repair tasks would fail if no sources were specified
