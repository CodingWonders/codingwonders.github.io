# DISMTools 0.8.2 Preview 1 - Now available

The first preview of DISMTools 0.8.2 is now available, with new features and enhancements.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.2_pre_2691)

## What's new?

- HotInstall and the Sysprep Preparation Tool now create rollback environments to undo boot configuration changes and environment deployments
- The Sysprep Preparation Tool now disables sleep mode when running preparation tasks
- You can now query and set Safe Mode preferences for services
- Getting information about items is now done asynchronously, making the UI responsive
- When dropping AppX packages to the addition queue, you will now see a progress indicator
- When scanning AppX packages, 7-Zip is now forced to use all your processors
- When enabling features, sources can now be configured to be used only on features that require them
- The window layout has been improved on 1024x768 screens
- 7-Zip has been updated to version 26.03
- Keyboard shortcuts have been added to create, open, and save projects
- DISMTools can now detect if the current network connection is metered and will warn you when attempting a download operation

## What's fixed?

- Fixed an exception when launching the AppX package information dialog on Windows 8 systems
