# Releasing DISMTools 0.8.1 Update 1

The September 2026 update of DISMTools 0.8.1 has been released. This version includes some enhancements and fixes from the first 2 previews of DISMTools 0.8.2.

<!-- more -->

[Download this release](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.1_upd1)

## What's changed?

- Fixed an exception when launching the AppX package information dialog on Windows 8 systems
- Fixed an issue where component store repair tasks would fail if no sources were specified
- ISO file creation tasks in the ISO creator can now be double-clicked to load their settings
- When scanning AppX packages, 7-Zip is now forced to use all your processors
- The window layout has been improved on 1024x768 screens
- 7-Zip has been updated to version 26.03
- The following libraries and components have been updated:

| Component | Previous version | New version |
|:--:|:--:|:--:|
| [Markdig](https://github.com/xoofx/Markdig) | `1.3.2` | `1.4.0` |

## How do I get started?

As always, you can begin contributing to the project by [**downloading this version today**](https://github.com/CodingWonders/DISMTools/releases/tag/v0.8.1_upd1) and **reporting feedback to us**.
